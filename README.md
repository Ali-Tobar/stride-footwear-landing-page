# Stride - Footwear Landing Page

A clean and responsive sneaker landing page built to practice and apply **Tailwind CSS v4** fundamentals along with basic **Vanilla JavaScript** for DOM interactivity.

---

## 📖 Overview

The goal of this project was to step away from traditional CSS and get hands-on experience with Tailwind's utility-first approach: building responsive layouts with Flexbox and CSS Grid, customizing transitions, and handling simple user interactions using plain JavaScript.

---

## ✨ Features

- **Responsive Header & Mobile Menu**: Sticky navigation bar with desktop links and a toggleable mobile hamburger menu.
- **Hero Section**: Full-screen banner with a linear gradient overlay and a smooth call-to-action button.
- **Store Perks (Features Bar)**: 4-column highlight section (Free Shipping, Returns, Safe Checkout, 24/7 Support).
- **Product Grid**: Responsive 6-card sneaker showcase with hover zoom animations, stock status, and prices.
- **Interactive Cart Counter**: Clicking "Buy Now" updates the cart badge count in real-time and provides visual button feedback (`Added ✓`).
- **Newsletter Section**: Clean call-to-action subscription form with a simple submit event.
- **Organized Footer**: 3-column footer containing brand info, quick navigation, and customer care links.
- **Smooth Navigation**: Smooth scrolling (`scroll-smooth`) between all sections.

---

## 🛠️ Built With

- **HTML5**: Clean, semantic structure.
- **Tailwind CSS v4**: Utility classes, responsive breakpoints (`md`, `lg`, `xl`), and transitions.
- **Vanilla JavaScript**: Basic DOM manipulation (`querySelector`, `addEventListener`, `classList.toggle`, `setTimeout`).
- **Google Fonts**: Poppins font.
- **SVG Icons**: Tabler Icons.

## 🚀 How to Run Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Ali-Tobar/stride-footwear-landing-page.git
   ```

2. Open the project folder:
   ```bash
   cd stride-footwear-landing-page
   ```

3. Open `index.html` directly in your browser, or launch it with the **Live Server** extension in VS Code.
